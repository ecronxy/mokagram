# Proposal

## Why

The user wants channels, basic groups, supergroups, private chats and Saved Messages in a manually selected feed.

## What Changes

Allow up to 32 distinct mixed sources per category, source-neutral labels, sender attribution and chronological message navigation. Preserve legacy categories and account isolation.

## Capabilities

### New Capabilities
- `feed-sources`: The user wants channels, basic groups, supergroups, private chats and Saved Messages in a manually selected feed.

### Modified Capabilities

## Impact

Native feed module and required localization only. Each change is independently reviewable.
