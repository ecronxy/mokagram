# Proposal

## Why

В окне плагинов при выключенном переключателе «Включить систему плагинов» карточки плагинов продолжают показывать горящий включённый тумблер, хотя на деле ни один плагин не работает (состояние `paused`). Это вводит в заблуждение.

## What Changes

- Пока система плагинов выключена, карточки плагинов затемняются и визуально читаются как неактивные.
- Тумблер плагина не показывается включённым, пока система выключена; сохранённый выбор пользователя (включён/выключен) не теряется и возвращается при включении системы.
- Включение/выключение системы обновляет вид карточек сразу, без переоткрытия окна.

## Capabilities

### New Capabilities
- `plugin-manager-ui`: отображение состояния плагинов в окне управления плагинами относительно общего выключателя системы плагинов.
