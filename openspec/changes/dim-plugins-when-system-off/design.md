# Design

## Context

`ListJson` отдаёт для каждого плагина `enabled` (= не в `_disabled`, выбор пользователя) и `state` (`paused`, когда система выключена). `AddPluginCard` рисует тумблер из `enabled`, поэтому при выключенной системе он горит. `EngineEnabled()` — источник истины о выключателе системы.

## Goals / Non-Goals

**Goals:**
- Тумблер и карточка отражают, что плагин не работает при выключенной системе.
- Живое обновление при переключении системы.

**Non-Goals:**
- Менять Python-хост, формат JSON и хранение состояния.
- Блокировать клики по тумблеру плагина при выключенной системе.

## Decisions

- Общий флаг `engineOn` (`shared_ptr<bool>`) и список callback'ов обновления создаются в окне; блок `engine` вызывает их из callback'а выключателя после `SetEngineEnabled`.
- Затемнение карточки через `QGraphicsOpacityEffect` (около 0.5) на панели карточки; альтернатива перерисовки цветов отвергнута как более громоздкая.
- Тумблер получает метод внешней установки состояния: показывает `enabled && engineOn`, сохранённый `enabled` из JSON не трогаем. Клик по тумблеру при выключенной системе по-прежнему сохраняет выбор через `SetEnabled`, но визуально остаётся выключенным до включения системы (допущение; при желании можно блокировать).

## Risks / Trade-offs

- Клик по затемнённому тумблеру может выглядеть как «ничего не произошло». Принято, чтобы не терять возможность заранее настроить плагины.
