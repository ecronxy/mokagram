# Spec Delta

## Purpose
Определяет, как окно управления плагинами показывает состояние плагинов, когда общая система плагинов включена или выключена.

## ADDED Requirements

### Requirement: Карточки плагинов отражают выключенную систему
Пока система плагинов выключена, окно плагинов SHALL показывать карточки плагинов затемнёнными, а их тумблеры выключенными, независимо от сохранённого выбора пользователя для конкретного плагина.

#### Scenario: Система выключена
- **WHEN** пользователь открывает окно плагинов при выключенной системе плагинов
- **THEN** все карточки затемнены и ни один тумблер плагина не горит включённым

#### Scenario: Переключение системы в открытом окне
- **WHEN** пользователь переключает «Включить систему плагинов» при открытом окне
- **THEN** карточки сразу затемняются или возвращаются к обычному виду, без переоткрытия окна

### Requirement: Выбор пользователя сохраняется
Выключение системы плагинов SHALL NOT менять сохранённое состояние включён/выключен отдельных плагинов.

#### Scenario: Возврат к прежнему состоянию
- **WHEN** система была выключена, а затем включена снова
- **THEN** плагины, которые были включены до этого, показаны включёнными и загружены, а выключенные остаются выключенными
